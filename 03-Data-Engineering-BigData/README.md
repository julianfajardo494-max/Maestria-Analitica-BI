## 📌 Descripción del Módulo

Este módulo consolida los desarrollos de **procesamiento masivo de datos (Big Data), arquitecturas Data Warehouse, pipelines ETL/ELT y streaming en tiempo real** desarrollados durante la Maestría en la Universidad del Valle.

## 🗂️ Contenido de laboratorios y proyectos

- **01-ETL-DataWarehouse-SQL**: Bodegas de datos y pipelines relacionales (SQL Server / PostgreSQL).
- **02-PySpark-BigData-Cluster**: Procesamiento distribuido masivo en PySpark y Hadoop.
- **03-Kafka-Event-Streams**: Streaming de datos y eventos en tiempo real con Apache Kafka.
